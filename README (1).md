# 🎉 Ahorro para mi cumpleaños

App web simple para planear los gastos de un cumpleaños y registrar el ahorro diario de cada uno.

## Funciones

- Lista de gastos: alquiler de sonido, comida, cerveza, mikes, decoración, DJ y gaseosas (vidrio).
- Define el presupuesto de cada gasto.
- Registra cuánto ahorras cada día; se descuenta de lo que falta.
- Barra de progreso por gasto y total.
- Elige la fecha del cumpleaños y ve cuánto ahorrar por día.
- Agrega o elimina gastos, y exporta/importa un respaldo en JSON.
- Los datos se guardan en el navegador (`localStorage`).

## Usar en local

Abre `index.html` en tu navegador.

## Publicar en GitHub Pages

1. Crea un repositorio nuevo en GitHub y sube `index.html`, `style.css`, `app.js` y `README.md`.
2. Ve a **Settings → Pages**.
3. En **Source** elige **Deploy from a branch**, rama `main`, carpeta `/ (root)` y guarda.
4. En un minuto tendrás tu app en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.

> Nota: los datos viven en cada dispositivo. Usa **Exportar / Importar** para pasarlos de un dispositivo a otro.
